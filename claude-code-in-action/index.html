이 과정에 대하여

이 과정은 언어 모델을 활용해 개발 작업을 수행하는 커맨드라인 AI 어시스턴트인 Claude Code를 다룹니다. Claude Code가 툴 시스템을 통해 파일을 읽고, 명령을 실행하고, 코드를 수정하는 방법과 함께 컨텍스트 관리, 커스텀 워크플로우 생성, 훅(hook)을 통한 Claude Code 확장, 외부 서비스와의 통합 기법을 배웁니다.

학습 목표

이 과정을 마치면 다음을 할 수 있습니다:

  • 파일 조작, 명령 실행, 코드 분석을 위한 Claude Code의 핵심 툴 활용
  • /init, Claude.md 파일, @ 멘션을 사용한 효과적인 컨텍스트 관리
  • 다양한 단축키와 명령어를 활용한 대화 흐름 제어
  • 복잡한 작업을 위한 Plan Mode와 Thinking Mode 활성화
  • 반복적인 개발 워크플로우 자동화를 위한 커스텀 명령어 생성
  • 브라우저 자동화 등의 기능 추가를 위한 MCP 서버로 Claude Code 확장
  • 자동화된 PR 리뷰 및 이슈 처리를 위한 GitHub 연동 설정
  • Claude Code에 추가 동작을 부여하는 훅(hook) 작성

사전 준비 사항

  • 커맨드라인 인터페이스(CLI) 기본 사용 경험
  • Claude Code 접근 권한 및 API 키

데이터 및 개인정보 보호

Skilljar는 교육 콘텐츠를 호스팅하는 학습 관리 시스템(LMS)입니다. Anthropic 강좌 자료에 접근하기 위해 이 플랫폼에 로그인합니다. 별도 플랫폼을 통해 인터랙티브한 학습 경험 제공, 학습 진도 추적, 모든 강좌 자료에 체계적으로 접근할 수 있도록 지원합니다.

Skilljar는 강좌 진도, 강의 수강 여부, 퀴즈 점수, 학습 소요 시간 등 기본적인 학습 분석 데이터를 수집합니다. 이 데이터는 학습 진행 상황 파악과 수료증 발급에 활용되며, 모든 수집은 Skilljar 개인정보 처리방침을 따릅니다.

Skilljar는 이 강좌 플랫폼 내의 학습 진도만 추적하며, Anthropic 계정은 Anthropic Console 및 Claude AI 서비스 접근을 관리합니다. 두 계정은 독립적으로 운영됩니다.

Skilljar는 데이터 암호화, 안전한 호스팅, 정기 보안 감사 등 업계 표준 보안 조치를 적용합니다. SOC 2 인증을 받았으며, 적절한 접근 제어가 갖춰진 보안 서버에 학습 데이터를 저장합니다.

Skilljar 계정 삭제를 원하시면 로그인 후 계정 설정에서 직접 삭제하거나, Skilljar 지원팀에 삭제를 요청하실 수 있습니다.

강좌 수강에 Anthropic 계정은 필요하지 않습니다. Skilljar 계정만으로 모든 강좌 콘텐츠에 접근할 수 있습니다. 단, Claude Code를 실제로 사용하려면 Anthropic API 키가 필요합니다.
